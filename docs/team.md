## 1일차 연습 PR
각자 `docs/team/내GitHub아이디.md` 파일 **하나만** 새로 만든다(이 표는 고치지 않는다 → 서로 충돌이 나지 않음).
양식:

```md
# 이름
- 역할:
- 쓰는 AI 코딩 도구: (예: Claude Code, Codex)
- 내 컴퓨터: (예: Mac, Windows)
- 한 마디:
```
브랜치·PR 제목은 각자의 작업 안내서(S1, K2, H1)를 따른다.
