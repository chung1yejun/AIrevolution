# 디자인 규칙 (design.md)

담당: 정예준 작성 · 공통 부품 구현: 김수아(S2, S3)
분위기: 장례 이후에 쓰는 서비스라 **차분하고 믿음직하게**. 밝은 원색, 과한 그림자·움직임, 이모지는 쓰지 않는다.

참고한 디자인: 토스(toss.im)처럼 **큰 제목 + 넉넉한 여백 + 아래쪽 큰 버튼 하나**. 테두리 있는 카드를 여러 개 늘어놓지 않고, 정보는 글로 간결하게 쓰고 면(연회색 배경)으로만 구분한다. 한 화면에서 말하는 것은 하나.

## 1. 색 (Tailwind `tailwind.config` 또는 CSS 변수로 등록)
| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| primary | `#2F5D62` (짙은 청록) | 주 버튼, 강조 글자, 진행률 막대, 선택된 탭 |
| primary-soft | `#E6EFEE` | 선택된 항목 배경, 태그 배경 |
| bg | `#FFFFFF` | 화면 배경(흰색) |
| surface | `#F2F4F6` | 카드·입력칸·보조 버튼 배경(연회색, 테두리 없음) |
| text | `#191F28` | 제목·본문 |
| text-sub | `#6B7684` | 보조 설명 |
| border | `#E5E8EB` | 구분선, 진행 막대 바탕 |
| warn | `#C2410C` | 기한 임박(D-14 이하), 오류 |
| warn-soft | `#FFF1E8` | 기한 임박 카드 배경 |
| done | `#15803D` | 완료 표시 |

## 2. 글자
- 글꼴: Pretendard(`pretendard` 패키지 또는 `next/font/local`), 없으면 시스템 기본 글꼴.
- 크기: **큰 제목(첫 화면·질문) 28px 굵게, 줄 간격 1.35** / 화면 제목 22px 굵게 / 섹션 제목 18px 굵게 / 본문 16px / 보조 14px / 아주 작은 안내 12px(되도록 쓰지 않음).
- 큰 제목은 글자 간격을 조금 좁힌다(`tracking-[-0.02em]`)와 `break-keep`.
- 본문 줄 간격 1.5. 숫자(D-day, 금액)는 굵게.

## 3. 간격과 모양
- 간격은 4의 배수(4, 8, 12, 16, 24, 32px). 화면 좌우 여백 16px.
- 모서리 둥글기: 카드 16px, 버튼·입력칸 16px, 태그 999px(알약 모양).
- 그림자와 테두리는 쓰지 않는다. 카드는 surface(연회색) 면으로 구분한다.
- 누르는 영역은 최소 높이 44px, 화면 아래의 주 버튼은 높이 56px.

## 4. 화면 틀
- 휴대폰 폭 375px 기준. 넓은 화면에서는 최대 480px 폭으로 가운데, 바깥 배경은 bg 색.
- 상단: 화면 제목(왼쪽), 필요하면 뒤로가기(왼쪽 화살표), 홈에서는 오른쪽에 내 정보 아이콘.
- 하단 탭: 높이 64px, 아이콘 + 글자 4개(홈, AI 분석, 서류, 맡기기). 선택된 탭은 primary 색. 내용이 탭에 가리지 않게 아래 여백.
- `/partner`는 PC 화면 최대 1200px, 숫자 카드 4개를 한 줄에.

## 5. 공통 부품 (`components/ui/`)
| 부품 | 규칙 |
|---|---|
| Button | 주(primary 배경, 흰 글자, 높이 56px, 둥글기 16px) / 보조(surface 연회색 배경, primary 글자, 테두리 없음) / 비활성(회색, 누를 수 없음). 기본 폭 100%. 누르는 중에는 로딩 표시 |
| Card | surface 배경, 테두리 없음, 둥글기 16px, 안쪽 여백 16px |
| Checkbox | 24px 정사각형, 체크하면 primary 배경과 흰 체크. 글자까지 누를 수 있게 |
| ProgressBar | 높이 8px, 배경 border 색, 채움 primary. 옆에 "3/9 완료" 글자 |
| Tag | 작은 알약 모양. 종류: 샘플(회색), AI 생성(primary-soft), 전문가 확인 필요(warn-soft + warn 글자), 기한 임박(warn) |
| Input, Select | 높이 56px, surface 배경, 테두리 없음, 선택 시 primary 테두리 2px. 위에 라벨, 아래 오류 문구(warn) |
| BottomTab | 4장 참고 |
| Loading | 카드 모양 회색 스켈레톤 3개 또는 가운데 스피너 + "불러오는 중이에요" |
| ErrorState | "문제가 생겼어요" + 이유 한 줄 + '다시 시도' 버튼 |
| EmptyState | 안내 문구 + 다음 행동 버튼 하나 |

## 6. 문구
- "~해요" 체. 짧게. 위로하는 말은 첫 화면 한 줄 정도만, 나머지는 할 일 중심.
- 법적 판단처럼 보이는 문장은 피하고 "전문가 확인이 필요해요"로 안내.
