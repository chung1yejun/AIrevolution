# 화면 명세 (screens.md)

파일 위치: 로그인 후 하단 탭이 있는 화면은 `app/(app)/` 아래(`/home` → `app/(app)/home/page.tsx`). `/`, `/about`, `/onboarding`, `/partner`는 `app/` 바로 아래.

담당: 정예준 · 함께 볼 문서: `specs/product.md`, `specs/design.md`(김수아), `specs/api.md`(강주원·황겸)

## 0. 공통
- **모바일 우선**: 기본 폭 375px. 넓은 화면에서는 최대 480px 폭으로 가운데 정렬(`/partner`만 PC 우선, 최대 1200px).
- **하단 탭**(로그인 후 화면): 홈(`/home`) · AI 분석(`/analysis`) · 서류(`/documents`) · 맡기기(`/delegate`). 현재 탭 강조.
  - 하단 탭이 없는 화면: `/`, `/about`, `/onboarding`, `/partner`.
- **상단**: 화면 제목, 필요하면 뒤로가기. 홈 오른쪽 위에 내 정보(`/me`) 버튼.
- **로그인 보호**: `/`, `/about`, `/partner`, `/auth/callback`을 뺀 화면은 로그인 필요. 아니면 `/`로 보낸다.
- **로그인 후 이동**: 답변이 없으면 `/onboarding`, 있으면 `/home`. 로그인한 사람이 `/`에 오면 같은 규칙으로 보낸다.
- **상태**: 로딩(스켈레톤 또는 스피너), 오류(무엇이 잘못됐는지 + 다시 시도 버튼), 빈 상태(무엇을 하면 되는지 안내 + 버튼).
- **샘플 표시**: 샘플 데이터가 나오는 카드에 '샘플' 태그.

## 1. 첫 화면 `/` (기능 1 · 정예준)
- 목적: 서비스 소개와 로그인.
- 보이는 것: 하늘상조 로고·이름, 서비스 한 줄 소개, 주요 기한 흐름(사망신고 1개월 / 상속포기·한정승인 3개월 / 상속세 신고 6개월), 'Google 계정으로 시작하기' 버튼, 하단 링크(이용 안내, 파트너용 화면).
- 동작: 버튼 → 구글 로그인 → `/auth/callback` → 이동 규칙대로.

## 2. 이용 안내 `/about` (기능 1 · 정예준)
- 보이는 것: 서비스 설명, AI 사용 안내(무엇을 AI가 하고 하지 않는지), 개인정보 처리(저장하는 것/안 하는 것, 국외 이전 고지: Claude API), 샘플 데이터 안내, 탈퇴 방법.
- 로그인 없이 볼 수 있다. 뒤로가기.

## 3. 로그인 콜백 `/auth/callback` (기능 1 · 강주원)
- 화면 없음. 로그인 처리 후 이동 규칙대로 보낸다. 실패하면 `/`로 보내고 오류 안내.

## 4. 질문 `/onboarding` (기능 2 · 정예준)
- 한 화면에 질문 하나, 위에 진행 단계(1/5 ~ 5/5)와 진행 막대.
- 질문과 선택지 (괄호 안은 API로 보내는 값, `specs/api.md` POST /api/answers):
  1. 고인과의 관계(`relation`): 배우자(spouse) / 자녀(child) / 부모(parent) / 형제자매(sibling) / 기타(other) / 잘 모르겠어요(unknown)
  2. 별세일(`deathDate`): 날짜 선택(YYYY-MM-DD). 오늘 이후 날짜와 1년보다 오래된 날짜는 고를 수 없다.
  3. 고인의 거주 지역(`region`): 서울, 부산, 대구, 인천, 광주, 대전, 울산, 세종, 경기, 강원, 충북, 충남, 전북, 전남, 경북, 경남, 제주
  4. 상속인 수(`heirCount`): 1명(1) / 2명(2) / 3명(3) / 4명 이상(4+) / 잘 모르겠어요(unknown)
  5. 유언장 유무(`will`): 있음(yes) / 없음(no) / 잘 모르겠어요(unknown)
- 버튼: 이전, 다음(답을 고르기 전에는 비활성). 마지막에 '할 일 만들기' → `POST /api/answers` → `/home`.
- 홈에서 '답변 수정'으로 다시 들어오면 기존 답이 채워져 있다.

## 5. 홈 `/home` (기능 3 · 정예준)
- 맨 위: 가장 급한 기한 카드(예: "상속포기·한정승인 D-82", 날짜 함께).
- 진행률 막대: 끝낸 일 / 전체 일.
- 할 일 목록: 제목, 기관, 기한, 체크박스. 기한이 가까운 순.
- 버튼: '답변 수정'(→ `/onboarding`), 'AI로 놓친 기관 찾기'(→ `/analysis`).
- API: `GET /api/home`, `PATCH /api/tasks/[id]`.
- 빈 상태: 답변이 없으면 질문으로 안내.

## 6. AI 분석 `/analysis` (기능 4 · 김수아)
- 단계: ① 샘플 조회 결과 불러오기(원문 미리보기, '샘플' 표시) ② 이름·주민번호 가리기 결과 미리보기 ③ '분석하기' → 분석 중(최대 20초) ④ 결과 카드(기관명, 종류, 건수, 'AI 생성' 표시, 원본 대조 안내) ⑤ 체크한 기관을 '할 일에 추가' → 홈.
- 실패 시: 예비 결과를 보여주고 "예비 결과를 보여드려요" 안내. 하루 5회 초과 시 안내.
- API: `POST /api/analysis`, `POST /api/analysis/apply`.

## 7. 준비 서류 `/documents` (기능 5 · 김수아)
- 서류별 카드: 서류 이름, 필요 부수, 발급처, 쓰이는 기관, 발급 체크.
- '기관 직접 추가' 버튼: 목록(`GET /api/institutions`)에서 골라 할 일로 추가(`POST /api/analysis/apply`).
- 빈 상태: 할 일이 없으면 질문·AI 분석으로 안내.
- API: `GET /api/documents`, `PATCH /api/documents/[id]`.

## 8. 기관 상세 `/institutions/[id]` (기능 6 · 김수아)
- 기관 이름·종류, 해야 할 일, 필요 서류, 신청 방법, '전문가 확인 필요' 표시(해당 시).
- 요청서 입력 폼(신청인 이름, 연락처, 고인 이름, 관계 등) → 'PDF 내려받기'(`lib/pdf.ts`, 서버로 보내지 않음).
- API: `GET /api/institutions/[id]`.

## 9. 맡기기 `/delegate` (기능 7 · 황겸)
- 맡길 할 일 선택 → 샘플 행정사 목록(지역, 처리 실적, 보수) → 선택 → 고지 확인 체크 → 신청.
- 내 신청 내역(행정사, 맡긴 일, 신청일, 상태).
- 고지 문구와 '샘플' 표시 필수.
- API: `GET /api/agents`, `POST /api/delegations`, `GET /api/delegations`.

## 10. 내 정보 `/me` (기능 1 · 정예준)
- 로그인한 구글 이메일, 로그아웃 버튼, 탈퇴 버튼(확인창: "모든 기록이 지워지고 되돌릴 수 없어요") → `DELETE /api/me` → `/`.
- 이용 안내 링크.

## 11. 파트너 대시보드 `/partner` (기능 8 · 황겸)
- PC 화면. 로그인 없이 링크로 연다(개인 정보 없이 집계 숫자만 표시).
- 숫자 카드: 이번 달 이용 가정 수, 청구 예정액, 평균 진행률, 정리 완료 가정 수.
- 최근 14일 신규 이용 그래프, 진행 단계별 가정 수 표.
- API: `GET /api/partner/stats`.
