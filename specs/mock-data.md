## 4. 샘플 조회 결과 (H5 → `lib/samples/inquiry-result.ts`의 문자열)
안심상속 조회 결과 통지 형식을 본뜬 텍스트. **가짜 이름과 가짜 주민번호가 들어 있어야** 가리기(S5)를 시험할 수 있다.
```
[샘플] 안심상속 원스톱서비스 조회 결과 통지

신청인 성명: 박서연   주민등록번호: 880412-2345678
사망자 성명: 박영수   주민등록번호: 520903-1234567
사망일: 2026-11-10   주소: 대구광역시 수성구 (샘플)

1. 금융거래 조회 결과
 - 하늘은행: 예금 2건
 - 든든생명: 보험 계약 1건
2. 자동차 조회 결과
 - 승용차 1대 (등록지: 대구)
3. 국세·지방세 조회 결과
 - 체납 없음
```
- 가리기 규칙(S5): 주민등록번호 형식(숫자 6자리-숫자 7자리)은 `******-*******`로, "성명:" 뒤의 이름은 "박**"처럼 첫 글자만 남긴다.

## 5. 예비 분석 결과 (H5 → `lib/samples/fallback-analysis.ts`)
AI가 실패하거나(20초 초과, 형식 오류, 키 없음) 하루 5회를 넘으면 이 결과를 보여준다. 위 샘플 조회 결과의 정답이다.
```json
{
  "items": [
    { "name": "하늘은행", "type": "bank", "count": 2 },
    { "name": "든든생명", "type": "insurance", "count": 1 },
    { "name": "차량등록사업소", "type": "car", "count": 1 }
  ]
}
```
- K13 점검용으로 조회 결과 샘플을 2개 더 만든다(기관 구성만 다르게, `lib/samples/inquiry-result-2.ts`, `-3.ts`).
