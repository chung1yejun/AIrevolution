# 남김 (AIrevolution)

장례 이후 유족이 해야 하는 해지·명의변경·상속 업무를 한곳에서 처리하게 돕는 모바일 웹 서비스입니다. 한양대 'AI혁명' 수업 팀 과제입니다.

## 실행 방법
```bash
npm install
npm run dev
```
브라우저에서 http://localhost:3000 을 엽니다. 휴대폰 화면은 크롬 F12 → 휴대폰 아이콘(375px)으로 확인합니다.

## AI와 함께 일하기
저장소 폴더에서 AI 코딩 도구(Claude Code, Codex)를 열고 이렇게 말합니다.
