## 목표
화면 담당(정예준, 김수아)이 묶음2부터 기다리지 않도록, api.md의 응답 예시를 그대로 돌려주는 가짜 API를 만든다.

## Step 1. 공통 함수 `lib/api.ts`
- `ok(data, status = 200)`: JSON 응답.
- `fail(status, code, message)`: `{ error: { code, message } }` 응답. code는 BAD_INPUT, UNAUTHORIZED, NOT_FOUND, SERVER_ERROR.
- 공통 타입(`Task`, `HomeResponse`, `AnalysisItem` 등)은 `lib/types.ts`에 api.md 모양 그대로 정의(화면도 이 타입을 쓴다).

## Step 2. 껍데기 6개
| 파일 | 메서드 | 돌려줄 것 |
|---|---|---|
| `app/api/answers/route.ts` | POST | `{ ok: true, taskCount: 5 }` |
| `app/api/home/route.ts` | GET | api.md의 답이 있을 때 예시 전체 |
| `app/api/tasks/[id]/route.ts` | PATCH | 받은 id와 done으로 예시 모양 |
| `app/api/analysis/route.ts` | POST | `source: "ai"` 예시 |
| `app/api/analysis/apply/route.ts` | POST | `{ added: 받은 items 수, skipped: 0 }` |
| `app/api/me/route.ts` | DELETE | `{ ok: true }` |
- 지금은 로그인 검사 없음(실제 버전 K6·K7·K9·K10·K11에서 추가). 파일 맨 위에 `// 껍데기(K4): 실제 버전은 K7에서` 같은 주석.
- 요청 본문이 JSON이 아니면 400 BAD_INPUT 정도만.
