# Y4. 뼈대 앱
- 담당: 정예준 · 구간: 1일차 11/18(수) · 끝나면 바로 단톡방 공지(팀원들이 이걸 받아서 시작)
- 브랜치: `feature/Y4-skeleton` · PR 제목: `[Y4] 정예준: 뼈대 앱`
- 읽을 것: CLAUDE.md 5·6장, specs/screens.md 0장, specs/design.md 1~2장
- 먼저 필요: Y2(md 파일이 main에 있음). **K1을 기다리지 않는다**(뼈대에는 Supabase·키가 필요 없음).

## 목표
팀원 모두가 같은 구조 위에서 시작하도록 Next.js 앱, 폴더 구조, 모바일 틀, 빈 화면 10개를 만들고 Vercel에 배포한다.

## Step 1. 준비
- `node -v`가 20.9 이상인지 확인(아니면 nodejs.org에서 LTS 설치). `git status`로 main이 깨끗한지 확인.
- `git checkout main` → `git pull origin main` → `git checkout -b feature/Y4-skeleton`

## Step 2. Next.js 만들기 (기존 md 파일 유지)
저장소 폴더에는 이미 md 파일이 있어서 바로 만들 수 없다. 옆의 임시 폴더에 만들고 옮긴다.
1. 저장소 바깥(한 단계 위)에서: `npx create-next-app@latest namgim-tmp --ts --tailwind --eslint --app --no-src-dir --import-alias "@/*" --use-npm --yes`
2. `namgim-tmp`의 파일을 저장소로 복사한다. **복사하지 않는 것**: `.git`, `node_modules`, `README.md`, `CLAUDE.md`, `AGENTS.md`(우리 것을 유지).
3. 저장소에서 `npm install` → 임시 폴더 삭제.
4. `.gitignore`에 `.env*`가 있으면 그 아래에 `!.env.example`을 추가(K2가 올릴 파일이 무시되지 않게).
- 확인: `npm run dev` → http://localhost:3000 에 Next.js 기본 화면.

## Step 3. 전체 틀과 디자인 값
- `npm install pretendard`
- `app/layout.tsx`: `<html lang="ko">`, 제목 '남김', Pretendard CSS import(`pretendard/dist/web/variable/pretendardvariable-dynamic-subset.css`), body에 배경색 bg.
- `app/globals.css`: 기본 예시 스타일을 지우고 Tailwind `@theme`에 design.md의 색(bg, surface, primary, on-primary, text, text-sub, border, field, warn, warn-ink, done, stem)과 글꼴을 등록 → `bg-primary`, `text-text-sub`처럼 쓸 수 있게.
- 이용자 화면 공통 폭: 최대 480px 가운데 정렬(`/partner`는 예외).
- `public/`의 기본 svg, 기본 `app/page.tsx` 내용은 지운다.

## Step 5. README와 PR
- 저장소 `README.md`: 서비스 한 줄 소개, 실행 방법(`npm install` → `npm run dev`), "AI에게 'CLAUDE.md 읽고 오늘 할 일 해줘'", 문서 위치(CLAUDE.md, specs/, tasks/README.md), 배포 주소(Step 6 후에 채움).
- `npm run lint`, `npm run build` 성공 확인 → commit `feat(Y4): 뼈대 앱` → push → PR → **정예준이 바로 Squash and merge**.
- (권장) GitHub Settings → General → Pull Requests: 'Allow squash merging'만 켜고, 'Automatically delete head branches' 켜기.

## Step 6. Vercel 배포
1. vercel.com(정예준 계정) → Add New → Project → GitHub `AIrevolution` Import → Framework: Next.js → Deploy.
2. Settings → Deployment Protection → **Vercel Authentication 끄기**(팀원·교수님이 미리보기 주소를 볼 수 있게).
3. 운영 주소(예: `https://airevolution-xxx.vercel.app`)를 README에 적는다(다음 PR Y5에 포함해도 됨).
4. 강주원에게 개인톡으로 운영 주소 전달 → 강주원이 Supabase 로그인 허용 주소에 추가(K2).
5. 강주원이 개인톡으로 연결 값을 보내면: Settings → Environment Variables에 4개 입력(`NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `ANTHROPIC_API_KEY`, 환경은 Production·Preview·Development 모두) → Deployments에서 Redeploy → **받은 메시지 삭제**.
