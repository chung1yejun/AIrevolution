## 목표
내 컴퓨터에서 앱을 실행하고, 브랜치 → commit → push → PR 흐름을 한 번 해 본다. `.env.local`은 아직 필요 없다.

## Step 1. 도구 확인
- `node -v`(20.9 이상), `git --version`. 없으면 설치 방법을 안내한다(nodejs.org LTS, git-scm.com).
- `git config user.name`, `git config user.email`이 비어 있으면 설정을 돕는다(이메일은 GitHub 계정 이메일).

## Step 2. 실행
- 저장소 폴더에서 `git checkout main` → `git pull origin main` → `npm install` → `npm run dev`
- 확인: http://localhost:3000 과 `/home`, `/analysis` 등 빈 화면이 열린다. 크롬 F12 → 휴대폰 아이콘 → 375px로 보기.

## Step 3. 연습 PR
- `git checkout -b feature/S1-setup`
- `docs/team/sua720.md` 파일 하나만 새로 만든다(양식은 docs/team.md). 내용은 사용자에게 물어서 채운다.
- commit `docs(S1): 팀원 소개 추가` → `git branch --show-current` 확인 → `git push -u origin feature/S1-setup`
  - 처음 push할 때 GitHub 로그인 창이 뜨면 로그인한다(`gh`가 있으면 `gh auth login`).
- PR 만들기: 제목 위와 같이, 본문은 PR 양식. '내가 판단하거나 고친 것'은 사용자가 직접 쓴다.
