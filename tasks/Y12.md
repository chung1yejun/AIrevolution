## Step 1. 처음부터 끝까지 (운영 주소, 휴대폰)
시크릿 창, 새 구글 계정으로:
1. 첫 화면 → 이용 안내 → 로그인 → 질문 5개 → 홈(기한, 진행률)
2. AI 분석(샘플 → 가리기 → 분석 → 추가) → 홈 반영
3. 서류 화면(합계, 체크), 기관 직접 추가
4. 기관 상세 → 요청서 PDF
5. 맡기기 신청 → 내역
6. 내 정보 → 로그아웃 → 다시 로그인하면 기록 유지 → 탈퇴 → 기록 삭제
7. `/partner`(PC, 로그인 없이) 숫자 확인
- 계정 2개로 기록이 섞이지 않는지 확인.

## Step 2. 버그 등록
- 구글 독스 'QA·버그' 탭에 Q-01부터: 화면·주소, 재현 순서, 기대 결과, 실제 결과, 심각도(P1 사용 불가 / P2 기능 오류 / P3 보기 불편), 담당(파일 담당 기준, CLAUDE.md 5장).
- 단톡방에 "버그 N개 등록, 각자 담당 확인" 공지.
