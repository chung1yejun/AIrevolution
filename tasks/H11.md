- 브랜치: 버그마다 `fix/Q-번호-영문설명`(예: `fix/Q-03-home-overflow`) · PR 제목: `[Q-번호] 황겸: 고친 것` · 커밋: `fix(Q-번호): 한 일`

## 보안 점검 (보완1, 결과는 QA 탭과 PR 본문에)
- [ ] 계정 A·B: B로 A의 할 일 id·서류·신청 내역 API를 불러도 보이지 않는다(404 또는 빈 결과).
- [ ] 모든 표 RLS 켜짐. 비로그인으로 `/api/partner/stats` 말고는 401.
- [ ] 브라우저 코드(F12 → Sources)와 GitHub 저장소에 service role·Anthropic 키가 없다(`git log -p`에서 키 형태 검색).
- [ ] analyses·DB 어디에도 조회 결과 원문, 주민번호, 요청서 입력값이 없다.
- [ ] `/partner`에 개인을 알아볼 값이 없다.
- [ ] 탈퇴하면 모든 표에서 행이 사라진다.
- 문제가 나오면 Q-번호로 등록하고 P1로 표시.

## 버그 하나를 고치는 Step
1. AI에게 "CLAUDE.md 읽고 Q-번호 버그 고쳐줘" → QA 탭 내용(재현 순서)을 붙여 준다.
2. 먼저 재현하고 원인을 쉬운 말로 설명 → 확인 후 수정. 버그 하나 = PR 하나.
3. 고친 뒤 재현 순서대로 다시 확인, 관련 화면이 깨지지 않았는지 확인.
4. lint·build → PR(본문에 Q-번호, 원인, 고친 방법, 확인 방법) → 단톡방 공유 → QA 탭 상태를 'PR'로, merge되면 '완료'.
- 내 담당이 아닌 파일이 원인이면 고치지 말고 QA 탭 담당을 바꿔 달라고 정예준에게 알린다.
