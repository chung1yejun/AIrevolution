# H6. 서류 API 실제
- 담당: 황겸 · 구간: 묶음3 11/23(월)~11/24(화) · PR 마감 11/24 22:00
- 브랜치: `feature/H6-documents-api` · PR 제목: `[H6] 황겸: 서류 API`
- 읽을 것: specs/api.md GET·PATCH /api/documents, specs/db.md(doc_checks, institution_documents)
- 먼저 필요: H3, H4, K3(requireUser)

## Step 1. GET /api/documents
- 로그인 확인 → 내 user_tasks의 institution_id 목록(중복 제거) → institution_documents와 documents를 합쳐 서류별로:
  - copies = 그 서류가 필요한 기관들의 부수 합, usedBy = 기관 이름 목록, checked = doc_checks에 행이 있는지.
- 할 일이 없거나 기관이 없으면 `{ documents: [] }`.

## Step 2. PATCH /api/documents/[id]
- `{ checked: boolean }` 검사 → true면 doc_checks에 insert(이미 있으면 그대로), false면 delete → `{ id, checked }`.
- 없는 서류 id면 404.
