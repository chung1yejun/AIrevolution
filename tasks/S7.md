# S7. 기관 상세(/institutions/[id])와 요청서 입력 폼

- 브랜치: `feature/S7-institution` · PR 제목: `[S7] 김수아: 기관 상세와 요청서 입력 폼`
- 읽을 것: specs/screens.md 8장, specs/api.md GET /api/institutions/[id]
- 먼저 필요: H4(H7이 묶음3에 merge됐으면 실제 데이터로 확인)

## Step 1. 기관 상세
- 상단 바(뒤로가기, 기관 이름), 종류, '샘플'·'전문가 확인 필요' 태그.
- 해야 할 일(체크 표시만, 체크는 홈에서), 필요 서류(이름·발급처·부수), 신청 방법.
- 상태: 로딩, 오류, 없는 기관(404) → "기관을 찾을 수 없어요" + 홈 버튼.

## Step 2. 요청서 입력 폼 (formKey가 있을 때만)
- 입력: 신청인 이름, 연락처, 고인 이름, 고인과의 관계, 별세일(질문 답으로 미리 채움 가능), 요청 내용(양식별 선택지: 은행 해지·예금 상속 / 보험금 청구·해지 / 휴대폰 해지·명의변경).
- 빈칸 검사, 연락처 형식 검사. **입력값은 화면 상태에만 두고 서버로 보내거나 저장하지 않는다**(CLAUDE.md 7장 2번).
- 'PDF 내려받기' 버튼은 자리만(S9에서 연결). formKey가 없으면 "이 기관은 방문 신청이에요" 안내.

## 완료 기준
- [ ] 할 일, 필요 서류, 신청 방법, 입력 폼 표시.
- [ ] 입력값이 네트워크 요청에 없다(F12 → Network 확인). lint·build 성공, PR과 단톡방 공유.
