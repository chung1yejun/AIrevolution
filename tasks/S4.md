# S4. AI 분석 화면(/analysis) 틀
- 담당: 김수아 · 구간: 묶음2 11/21(토)~11/22(일) · PR 마감 11/22 22:00
- 브랜치: `feature/S4-analysis` · PR 제목: `[S4] 김수아: AI 분석 화면 틀`
- 읽을 것: specs/screens.md 6장, specs/api.md POST /api/analysis, /api/analysis/apply
- 먼저 필요: K4(껍데기 API), S2

## 목표
불러오기 → 가리기 미리보기 → 분석 중 → 결과 카드 → 할 일 추가의 흐름을 껍데기 데이터로 만든다. 샘플 원문·가리기는 S5·H5가 이번 묶음에 만들므로 지금은 화면 안의 임시 문자열을 쓴다(S8에서 교체).

## Step 1. 단계 화면
- ① '샘플 조회 결과 불러오기' 버튼 → 원문 미리보기 카드('샘플' 태그) ② 가린 결과 미리보기(지금은 임시 문자열) ③ '분석하기' → 분석 중 화면(최대 20초 안내).
- 단계 상태는 한 `'use client'` 컴포넌트에서 관리.

## Step 2. 결과와 추가
- `POST /api/analysis` 결과 카드: 기관명, 종류(은행/보험/통신/자동차/공공), 건수, 'AI 생성' 태그, "원본과 꼭 대조해 주세요" 안내. 각 카드에 체크(기본 체크).
- `source`가 fallback이면 "예비 결과를 보여드려요" 안내, reason이 limit이면 "오늘 AI 분석 5회를 모두 썼어요" 안내. `remaining` 표시.
- '할 일에 추가' → `POST /api/analysis/apply`(`source: "ai"`, 체크한 items) → "N개를 추가했어요" → 홈 버튼.
