## 목표
팀원이 묶음1부터 로그인·DB를 쓸 수 있게 연결 값의 이름을 저장소에 올리고, 값은 개인톡으로만 전달한다.

## Step 1. 실행
- `node -v`(20.9 이상), `git config user.name/email` 확인 → `git checkout main` → `git pull origin main` → `npm install` → `npm run dev`
- 확인: http://localhost:3000 과 빈 화면들이 열린다.

## Step 2. .env.example과 내 .env.local
- `git checkout -b feature/K2-env`
- 저장소 루트에 `.env.example`(값 없이 이름만):
```
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
ANTHROPIC_API_KEY=
ANTHROPIC_MODEL=
```
- `ANTHROPIC_MODEL`은 비밀이 아닌 모델 이름(K8에서 사용, Anthropic 문서의 작고 빠른 모델).
- 내 컴퓨터에만 `.env.local`을 만들고 값을 채운다. `git status`에 `.env.local`이 **안 보이는지** 확인(보이면 멈추고 .gitignore 확인).

## Step 3. 연습 PR
- `docs/team/joowon0130.md` 하나만 추가(양식은 docs/team.md).
- commit `chore(K2): .env.example 추가` → 브랜치 이름 확인 → push → PR.

## Step 4. 연결 값 전달 (개인톡만, 단톡방·GitHub 금지)
| 받는 사람 | 보내는 값 | 이유 |
|---|---|---|
| 정예준 | 4개 모두 + ANTHROPIC_MODEL | Vercel 환경 변수 입력 |
| 김수아, 황겸 | `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` | 내 컴퓨터에서 로그인 확인 |
- 서버 전용 키(service_role, Anthropic)는 강주원·정예준만 갖는다. 다른 사람 컴퓨터에서 AI 분석은 `no_key` 예비 결과로 동작하고, 실제 AI는 미리보기 주소에서 확인한다.
- 받은 사람은 `.env.local`에 넣고 메시지를 삭제하도록 안내.

## Step 5. Vercel 주소를 로그인 허용 주소에 추가
- 정예준에게 받은 운영 주소를 Supabase → Authentication → URL Configuration → Redirect URLs에 `https://운영주소/**` 추가.
- 미리보기 주소도 로그인되게 Vercel 미리보기 주소 형식(예: `https://airevolution-*-계정.vercel.app/**`)을 추가.
- Site URL은 운영 주소로 바꾼다.
