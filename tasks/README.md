## 2. 마감 규칙
- 한 구간(묶음)은 2일. **묶음 마지막 날 22:00까지 PR**을 올린다. 작업이 2개면 PR도 2개.
- 정예준이 **다음 날 낮 12시까지** 리뷰하고 Squash and merge. **merge는 정예준만 해요.** 다른 팀원은 merge하지 않아요(CLAUDE.md 9장).
- 같은 묶음 안에서는 서로 기다리지 않는다. 화면은 앞 묶음에서 끝난 API나 껍데기 API를 쓴다.
- PR을 올리면 단톡방에 **PR 링크 + 휴대폰 화면 스크린샷**. merge되면 구글 독스 '팀원' 탭의 내 이름 탭에 체크와 PR 링크.
- 밀리면 단톡방에 먼저 알리고, 다음 묶음 첫날 안에 끝낸다. 표에서 앞 구간의 내 작업이 아직 merge 안 됐으면 그것부터 한다.
- 대면은 화요일 10분만: 11/24(중간 점검), 12/1(1차 완성 결과·버그 배정), 12/8(최종 확인). 나머지는 전부 비대면.

## 5. 작업 안내서 읽는 법
- 맨 위: 담당, 구간·마감, 브랜치 이름, PR 제목, 읽을 specs, 먼저 필요한 작업.
- **Step**: AI는 Step 하나를 끝내면 멈추고 확인 방법을 알려 준다. 사용자가 확인하면 commit 후 다음 Step.
- **완료 기준**: PR을 올리기 전에 하나씩 확인한다. PR 본문 '확인 방법'에 적는다.
- 안내서와 specs가 다르면 specs가 맞다. 둘 다 이상하면 단톡방에서 정예준에게 묻는다.
