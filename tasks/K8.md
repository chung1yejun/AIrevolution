- 먼저 필요: K1(키), H5(샘플; 같은 묶음 전이면 mock-data.md 4장 문자열로 확인)

## Step 1. 호출 함수
- `npm install @anthropic-ai/sdk`
- `lib/claude.ts`(서버 전용, 파일 맨 위 `import 'server-only'` — 없으면 `npm install server-only`):
  - `extractInstitutions(maskedText): Promise<AnalysisItem[]>`
  - 모델은 `process.env.ANTHROPIC_MODEL`, 키는 `ANTHROPIC_API_KEY`. 키가 없으면 `NoKeyError`.
  - 시스템 프롬프트: "조회 결과에서 기관명, 종류(bank/insurance/telecom/car/public), 건수만 JSON 배열로 추출. 다른 말 금지. 개인정보는 출력하지 않음." 프롬프트 문자열은 PR 본문에도 적는다.

## Step 2. 형식 검사
- 응답을 JSON으로 읽고 검사: 배열, 각 항목 name(문자열 1~50자), type(5개 중 하나), count(1 이상 정수). 하나라도 틀리면 `InvalidFormatError`.
- JSON 앞뒤에 글이 붙어 오면 대괄호 부분만 꺼내 한 번 더 시도.

## Step 3. 확인
- 임시 스크립트(`npx tsx`)로 샘플 조회 결과를 가린 뒤 넣어 결과를 출력하고, PR 본문에 붙인다. 스크립트는 PR에 넣지 않는다.

- [ ] Claude 응답이 정해진 JSON 형식으로 검사된다. 키 없음·형식 오류가 구분된다.
- [ ] 키가 코드·PR에 없다. lint·build 성공, 단톡방 공유.
