# S11. 보완 기간: 배정된 화면 버그 수정
- 담당: 김수아 · 구간: 보완1~4 12/1(화)~12/8(화) · **12/7(월) 밤 코드 동결**
- 브랜치: 버그마다 `fix/Q-번호-영문설명`(예: `fix/Q-03-home-overflow`) · PR 제목: `[Q-번호] 김수아: 고친 것` · 커밋: `fix(Q-번호): 한 일`
- 읽을 것: 구글 독스 'QA·버그' 탭의 내 담당 버그, 해당 기능의 specs
- 먼저 필요: Y12(버그 배정)

## 일정
- 보완1(12/1~12/2): 12/1 대면 10분에서 내 버그 확인. 팀 밖 사람 2명에게 운영 주소로 테스트 → 막힌 곳을 QA 탭에 등록.
- 보완2(12/3~12/4): P1 → P2 → P3 순서로 수정.
- 보완3(12/5~12/6): 외부인 테스트 2차, 새 버그 수정.
- 보완4(12/7~12/8): 12/7 밤 이후는 정예준이 허락한 P1만. 12/8 구글 독스 이름 탭 기록과 '내 파트 요약'(5줄) 마감.

## 버그 하나를 고치는 Step
1. AI에게 "CLAUDE.md 읽고 Q-번호 버그 고쳐줘" → QA 탭 내용(재현 순서)을 붙여 준다.
2. 먼저 재현하고 원인을 쉬운 말로 설명 → 확인 후 수정. 버그 하나 = PR 하나.
3. 고친 뒤 재현 순서대로 다시 확인, 관련 화면이 깨지지 않았는지 확인.
4. lint·build → PR(본문에 Q-번호, 원인, 고친 방법, 확인 방법) → 단톡방 공유 → QA 탭 상태를 'PR'로, merge되면 '완료'.
- 내 담당이 아닌 파일이 원인이면 고치지 말고 QA 탭 담당을 바꿔 달라고 정예준에게 알린다.
