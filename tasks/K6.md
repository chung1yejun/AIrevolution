## Step 1. 입력 검사와 저장
- `requireUser()`로 로그인 확인(401).
- 값 검사: screens.md 4장의 코드만 허용, deathDate는 YYYY-MM-DD·미래 불가·1년 초과 불가 → 400 BAD_INPUT.
- answers에 upsert(camelCase → snake_case: deathDate → death_date, heirCount → heir_count).

## Step 2. 규칙 할 일 다시 만들기
- `buildRuleTasks(answers)` 결과로:
  - 이미 있는 같은 rule_key 할 일은 제목·기한·기관만 갱신하고 done은 유지.
  - 없던 rule_key는 추가(source = 'rule', institution_id는 institutions의 key로 찾기).
  - 조건이 사라진 rule_key 할 일은 삭제. source가 ai·manual인 할 일은 건드리지 않는다.
- 응답 `{ ok: true, taskCount }`(규칙 할 일 수).

## Step 3. 확인
- 로그인 후 질문 화면에서 저장 → Supabase Table Editor의 answers·user_tasks에 내 행.
- 유언장을 no → yes로 바꿔 다시 저장 → will_probate 생기고, 체크해 둔 할 일은 체크 유지.
